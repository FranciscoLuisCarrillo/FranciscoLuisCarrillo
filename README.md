  * Diseño de estructura, roles y alertas automatizadas en célula cross-product bajo marco Scrum.

  * Gestión funcional y operativa del entorno de testing y trading algorítmico, despliegue de releases y mantenimiento de VMs Linux (logs vía PuTTY).
